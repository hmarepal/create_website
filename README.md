# Hemal Marepalli Portfolio

## Project Description

This project is a personal academic portfolio website created for CS 3365 - Software Engineering! 

The website presents information about me, my academic background, technical interests, skills, projects, and CV. The project was developed using Git and GitHub with a feature-branch workflow to demonstrate version control, incremental development, branching, merging, and deployment.

The current CV is a dummy cv used for the project and will be updated later.
